# Celestial Library prototype

Original prototype source and image assets extracted from `celestial-library-website-prototype.zip`. Application files are unchanged.

## For Arena

Read `ARENA_SOURCE.md` for the complete application source in one file. Original files remain in `src/`; environment images are in `public/images/`. Apply the revision prompt supplied separately. This repository is a prototype, not a production deployment.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The original prototype build was verified successfully. Reading progress, bookmarks, and notes use browser-local storage; account synchronization is not implemented.
